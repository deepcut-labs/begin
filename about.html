About

Deepcut Labs, LLC

A California software company building native Mac applications for developers.

What we do

We build small, focused Mac apps for people who write software. Our current work centres on the tooling around AI coding agents — the configuration those agents run on, and the record of what they actually did — and on the everyday Finder utilities that make a developer's Mac faster to work in.

Two products ship today: Agent Configurator, a library and deployment tool for AI agent configuration that also reads your session transcripts back as usage and cost reporting; and MDview, a free Quick Look preview extension that renders Markdown in Finder using your own stylesheets.

How we build

Everything we ship is a genuinely native Mac app — SwiftUI and AppKit, sandboxed, signed and notarized, built to the Apple Human Interface Guidelines. That means light and dark appearance are both first-class, every control is reachable from the keyboard and the menu bar, and VoiceOver works throughout rather than as an afterthought.

We prefer plain files to proprietary databases. Agent Configurator's library is a folder of Markdown files with YAML frontmatter; MDview's stylesheets are ordinary CSS. Both are readable, diffable and version-controllable with the tools you already use, and both keep working if you stop using our software.

Privacy, stated plainly

We operate no servers, no accounts and no analytics. Our apps read files that are already on your Mac and keep the results there. Network access happens only when you invoke a feature that needs it, using credentials you supplied, to a service you chose. Nothing is reported back to us — there is nowhere for it to go. The full detail, per product, is in our privacy policy.
